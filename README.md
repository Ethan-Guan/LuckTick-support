# LuckTick Support

Support page and privacy policy for LuckTick, the daily-fortune app for Apple Watch, published with GitHub Pages:

- Support: https://ethan-guan.github.io/LuckTick-support/
- Privacy Policy: https://ethan-guan.github.io/LuckTick-support/privacy.html

Each language has its own pages (`zh-Hans/`, `en/`, `ja/`, `ko/`); the root pages send visitors to the version matching their browser language.

To edit: change the text in `content/`, run `python3 build.py`, then commit and push.
